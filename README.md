# PureLeaf - Tea Factory Frontend Web

A modern web application for the PureLeaf Tea Factory Management System, providing managers and administrators with real-time dashboards, supply chain tracking, and operational tools. Built with React.js, Tailwind CSS, and Vite for fast development and performance.

---

## 🚀 Features

- Real-time dashboard for factory operations  
- User authentication and role-based access  
- Supply chain and shipment tracking  
- Automated reporting and analytics  
- Notifications and alerts  
- Responsive design for desktop and tablet  

---

## 🛠️ Technology Stack

- React.js  
- Tailwind CSS  
- Vite  
- Axios (for API requests)  
- React Router

## ⚡ Getting Started

Clone the repository:
```
git clone https://github.com/3rd-year-project-14/tea-factory-frontend-web.git
cd tea-factory-frontend-web
```

Install dependencies:
```
npm install
```
Start the development server:
```
npm run dev
```
